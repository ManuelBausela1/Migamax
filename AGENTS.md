# Reglas del proyecto

- Mantener React, TypeScript, Tailwind y la estructura actual de `src/`.
- No inventar datos de Migamax: productos, fotos, precios, dirección y teléfonos requieren aprobación.
- La web prepara consultas para WhatsApp; no confirma pedidos ni cobra online.
- Antes de subir cambios, ejecutar `npm run build`.
- Trabajar directamente en `main`. No agregar pruebas, workflows o procesos de PR salvo que el usuario los pida.
- Si se hace un commit, usar Conventional Commits (`feat:`, `fix:`, `style:`, `refactor:`, `docs:` o `chore:`) con una descripción concreta. El usuario quiere hacer sus propios commits salvo que indique lo contrario.
